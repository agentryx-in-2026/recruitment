How to mark a result

  1. In Verify open Test run and go to the session.
  2. Do the steps on Lite and compare with Expected.
  3. Mark Pass (all as expected), Fail (wrong or broken) or Partial (some parts fine, or you could only test part).
  4. For Fail or Partial, write what you saw and attach a screenshot.

Cases are in story order: each session uses what the one before it created. Do them in order.

Anything else

  • Report a finding (top bar in Verify) — anything wrong that no case covers.
  • Ask for help — questions about a case or the portal.
  • The automated checks run separately; their result is shown on each case, but your mark is the one that counts.

Rules

  • Do not press Run lifecycle in Admin → Lifecycle. It can close every job on the portal.
  • Before changing a setting, note the old value; put it back when the case is done.
  • Emails are real now. Only use your own addresses (the +uat trick), never someone else's.
  • Don't delete or close UAT Welder — Piyush — your applicant applies to it.
